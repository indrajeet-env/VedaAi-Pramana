# Pramana — A Product of VedaAI

## What is Pramana?

**Pramana (प्रमाण)** is a Sanskrit word which broadly means *evidence, proof, or that which establishes truth*. In Indian philosophical traditions, a *pramana* is a reliable method through which something is known or established to be true.

The name reflects the core idea behind **VedaAI Pramana**: **An AI system for establishing the validity of knowledge**.

## What does Pramana do?

Pramana uses **AI and OCR** to process a question paper and a student's handwritten answer sheet, automatically extracting questions and answers and evaluating them against the questions.

It provides **marks, feedback, strengths, weaknesses, unclear portions, and answer locations highlighted directly on the answer sheet**.
